# Zeraaty AI | زرعتي

منصة زراعية عربية لإدارة محاصيل القمح والطماطم، ومتابعة الري واستهلاك المياه، مع صلاحيات منفصلة للمزارع والمدير.

## المميزات الحالية

- إنشاء حساب مزارع وتسجيل الدخول والخروج.
- إدارة المحاصيل وتسجيل بيانات الحقول.
- تسجيل كميات مياه الري لكل محصول.
- لوحات وتقارير منفصلة حسب صلاحية المستخدم.
- عزل بيانات كل مزارع عن حسابات المزارعين الآخرين.
- حماية النماذج باستخدام CSRF والتحقق من المدخلات.

## المتطلبات

- Windows مع XAMPP.
- PHP 8.2 أو إصدار متوافق مع المشروع.
- MySQL أو MariaDB.
- إضافات PHP المطلوبة: PDO_MYSQL، GD، وملحقات الصور المستخدمة في المشروع.

## التثبيت المحلي

1. ثبّت XAMPP وشغّل Apache وMySQL.
2. انسخ مجلد المشروع إلى:
   `C:\xampp\htdocs\zeraaty_ai`
3. افتح phpMyAdmin.
4. استورد الملف `database/schema.sql`.
5. انسخ `config/database.example.php` إلى `config/database.php`.
6. اضبط متغيرات البيئة التالية في بيئة تشغيل PHP:
   - `ZERAATY_DB_HOST`
   - `ZERAATY_DB_NAME`
   - `ZERAATY_DB_USER`
   - `ZERAATY_DB_PASSWORD`
7. تأكد أن حساب قاعدة البيانات يملك الصلاحيات اللازمة على قاعدة المشروع فقط.
8. افتح:
   `http://localhost/zeraaty_ai/`

لا تستخدم حساب root بلا كلمة مرور في بيئة مكشوفة للشبكة، ولا ترفع ملف database.php أو أي بيانات اعتماد إلى GitHub.

## إنشاء حساب المدير

من سطر الأوامر داخل مجلد المشروع شغّل:

`C:\xampp\php\php.exe scripts\create_admin.php`

اتبع التعليمات لإنشاء حساب المدير. لا ترفع بيانات الحساب إلى المستودع.

## قاعدة البيانات

يحتوي مخطط البداية على الجداول الأساسية:

- `users`
- `crops`
- `irrigation_logs`

يبدأ المخطط دون بيانات مزارعين حقيقية.

## حالة تحليل الصور والذكاء الاصطناعي

توجد مكونات وتجارب برمجية لمعالجة صور النباتات واختبار عميل خدمة تحليل خارجية. لا تعتبر خدمة التحليل الخارجي أو رفع الصور ميزة تشغيلية متاحة في النسخة الحالية؛ يجب إعداد الخدمة ومفتاحها والتحقق من الاتصال والموافقة على إرسال الصور قبل تفعيلها.

## الاختبارات

توجد اختبارات تطوير داخل مجلد `scripts`. لا تُشغّل اختبارات الكتابة على قاعدة بيانات تحتوي على بيانات حقيقية. استخدم قاعدة اختبار منفصلة.

## استخدام الذكاء الاصطناعي

تم استخدام أدوات ذكاء اصطناعي للمساعدة في التطوير والمراجعة والصياغة. يجب على أعضاء الفريق مراجعة الكود وفهمه والقدرة على شرح الأجزاء التي نفذوها.
